# 调研：电脑运维与维修需求（Only-U 调研依据）

- 日期：2026-08-22
- 方式：公开 web 资料（维修工单统计、桌面运维问答、行业报告、IT helpdesk 经验帖）
- 用途：给 [only-u-agent-专业提示词.md](only-u-agent-专业提示词.md) 提供需求依据，给讲稿和评委问答提供数据弹药。**不改产品范围**（ADR-0002 为准）。

## 结论速览

1. 电脑维修需求高度集中：**C 盘满 / 卡顿 / 蓝屏 / 打印机 / 网络** 五类覆盖日常工单的七八成，且其中约 80% 用户自查即可解决——正好是 Only-U「诊断 + 清理」的覆盖区。
2. 用户最大痛点不是"不会修"，而是**怕删错文件**、被"一键清理"工具反伤（实测误删系统缓存后开机慢 20–40 秒）。
3. 专业判断的硬指标集中在几条阈值：**C 盘剩余 10%–15% 警戒线、磁盘使用 80% 性能拐点、启动项堆积、驱动冲突（占卡顿原因约 27%）**。

### 维修工经验（8 年接单）

开机慢、卡顿、WiFi 连不上、风扇噪音、间歇黑屏、按键失灵、自动重启、蓝牙故障、磁盘无法识别、无声——10 类占接单量**七成以上**，绝大多数是软件/习惯问题而非硬件损坏。典型案例：用户以为要换硬盘（500 元），实际是启动项堆积十几个 + C 盘只剩几百 MB，清理后开机 15 秒。

## 2. 需求分类与成因

### 2.1 空间与性能（最高频）

- **C 盘满**：低于 10%–15% 时虚拟内存无法展开，系统响应急剧下降；磁盘使用超 80% 性能明显下滑（SSD 因整块擦写机制更明显）。
- **启动项堆积**：现代电脑平均驻留后台进程 217 个；禁用非必要启动项实测可缩短开机 37%。
- **驱动冲突**：约占卡顿原因 27%。
- **多款杀软/优化软件并存**：互相监控冲突造成"负优化"（如 360 + 腾讯管家）。
- **散热积灰**：清灰换硅脂后 CPU 频率可从 2.2GHz 回升至 3.6GHz。
- **硬件老化**：内存故障致卡顿概率 39%；机械盘换 SSD 被评价为"性价比最高升级"。

### 2.2 系统稳定性（蓝屏/死机/自动重启）

- 常见原因：显卡驱动冲突（如 NVIDIA 与 Win11 兼容问题曾致大规模蓝屏）、内存金手指氧化（占内存故障 80%）、硬盘坏道。
- 专业处置：记录错误代码 → 查近期驱动/更新 → 内存/硬盘检测 → 复位。

### 2.3 外设（打印机 7.5%，外设类第一）

- 常见：驱动过旧、打印服务未运行、队列卡单、端口配置错误。

### 2.4 网络（4.7%）

- WiFi 连不上、能上 QQ 打不开网页（DNS）、代理残留。

### 2.5 硬件咨询

- 加 SSD、加内存是最高频升级需求；但硬件维修（换屏、清灰、电池）应引导去门店。

## 3. 用户痛点与行为误区

| 痛点 | 表现 | 对 Only-U 的意义 |
|---|---|---|
| 怕删错 | 不敢自己清 C 盘，宁可付费送修 | **误删防护**是核心卖点，比"清得多"重要 |
| 认知误区 | 以为"删文件=提速"，乱删系统缓存 | Agent 要教育：精准清理 ≠ 粗暴清空 |
| 第三方工具反伤 | 一键清理删 Prefetch/SoftwareDistribution，开机慢 20–40 秒；注册表清理被微软明确不建议 | Agent 永不推荐第三方清理/注册表工具 |
| 要"简单+原生+不捆绑" | 用户渴望不依赖第三方软件的安全方案 | U盘包定位正中：不安装、脚本原生 |
| 要长效维护 | 一次性清理效果只维持几个月 | Agent 可给"每月一次体检"建议 |
| 分不清责任 | 系统缺陷（休眠文件占 10–30GB）vs 使用习惯（微信聊天记录几十 GB）各占一半 | 诊断报告要分清"系统占用"与"用户文件"，后者不碰 |
