Only-U U盘包

插上盘后双击：

  诊断.cmd        没网也能用。看 C 盘、临时目录、近期错误、打印机。
  清理预览.cmd    只预览可回收量，不删除。确认后再运行 portable\clean.cmd -Execute。
  启动Agent.cmd   有网才用。打开 TUI，对它说「C 盘满了，帮我看看」。
  清空维修记录.cmd  借盘/卖盘前用。Y=只清客户对话（留维修记录）；A=连记录一起清。

TUI 里的常用入口

  直接说话        agent 会自己动手跑命令（PowerShell 工具已挂载）。
  !命令           !ipconfig —— 本地跑命令，结果只给你看，不给 agent。
  !!命令          !!ipconfig —— 同上，结果还会发给 agent 接着分析。
  /chajian        看装了哪些插件、有哪些命令和模型工具。
  /diagnose       跑完整诊断，报告存 portable\logs\diagnose-*.txt。
  /clean          清理预览（只算可回收空间，不删除），确认后运行。
  /space          全屏看 CPU/内存/磁盘/GPU 色块面板（r 刷新，Esc 退出）。
                  拼音别名：/kongjian
  /preset only-u-repair   切维修模式（只挂 PowerShell 与 Only-U 工具）。
  /preset standard        切回标准模式（默认）。
  留档                    对 agent 说「留档」：报告进 portable\reports\，台账追加 portable\history-<机器名>.md。

换自己的模型（三十秒）

  在 TUI 里输入 /provider → 自定义 → 贴 API 地址和 Key → 自动发现模型 →
  立即切换。凭据保存在 U 盘上，换电脑也在。

  常见地址（都是 OpenAI 兼容）：
    智谱   https://open.bigmodel.cn/api/paas/v4
    Kimi   https://api.moonshot.cn/v1
    通义   https://dashscope.aliyuncs.com/compatible-mode/v1
    本地   http://127.0.0.1:8000/v1   （vLLM/Ollama 等）

  提示：第三方模型如果不支持深度思考，输入 /effort 把思考调到 off。

注意

  不要输入 /update。
  不要把 portable\.env 发到 GitHub 或聊天里。
  重复双击只会开一个窗口。
