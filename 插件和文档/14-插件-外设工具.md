# ⑭ 外设工具插件（only-u-peripheral）

## 1. 概述

功能域：**外设检测（键盘/鼠标/U盘）**。内置 U 盘扩容检测脚本（写盘+读回校验）+ 调度宽松协议的第三方外设工具（键盘测试、鼠标回报率、存储芯片识别）。对标图吧工具箱「外设工具」分类。

- 包名：`only-u-peripheral`
- 开发状态：**已实现**（内置扩容检测可直接用；调度框架完成，工具收录待实测）
- 插件形态：标准 dsh.bundle 包，注册工具 `peri_tool_list` / `peri_tool_run` / `peri_usb_verify`

## 2. 构成

```
plugins\only-u-peripheral\
  package.json  cordis.patch.yml  index.js
  lib\
    catalog.js   runner.js   exitcodes.js   # 调度框架（各带副本，包自足）
    runScript.js  approve.js               # 内置脚本执行器 + 审批门
  assets\
    usb-verify.ps1    # U盘扩容检测：写测试数据 → 读回校验（写盘类，确认门）
  knowledge\
    peripheral-tools.json      # 生效知识库（空 = fail-closed）
    candidates.peripheral.json # 候选：kbt / MouseTester / CompuTester / ChipInfo（待实测）
    README.md
  tools\                       # 工具二进制随包分发（当前为空）
```

## 3. 应用场景

| 场景 | 触发条件 | 本插件做什么 |
|------|----------|--------------|
| A U盘容量验证 | 新盘/低价盘验货 | peri_usb_verify 写入+读回校验（确认门） |
| B 键盘测试 | 按键失灵/冲突 | peri_tool_run（kbt TUI，收录后） |
| C 鼠标测试 | 鼠标漂移/回报率 | peri_tool_run（MouseTester，收录后） |
| D 主控识别 | U盘损坏想量产 | peri_tool_run（ChipInfo，收录后） |

## 4. 场景提示词（直接复制进 TUI 使用）

**场景 A「U盘验容」**
> 新买的 U 盘，帮我验证一下是不是扩容盘。写入约 100MB 测试数据再读回校验，执行前先向我确认；测试文件用完即删。

**场景 B「键盘测试」**
> 键盘有几个键好像不灵，帮我列出可用的键盘测试工具，说明怎么操作。

## 5. 使用方法

1. U 盘验容：`peri_usb_verify({ drive, sizeMB })` —— 写盘类，**弹确认条**后才执行；完成后模型解释写速/读速/校验结论。
2. 键盘/鼠标/主控 → `peri_tool_list` → `peri_tool_run({ tool, params })`。

## 6. 安装方法

```bat
cd dsh
pnpm dsh plugin --profile dsh-tui add ..\plugins\only-u-peripheral
```

纯 harness：`dsh plugin --profile ops add ..\plugins\only-u-peripheral`。

## 7. 开发要点

### 7.1 已实现

- **内置 `peri_usb_verify`（可用）**：默认自动选第一个可移动磁盘（或指定 `drive`），写入 100MB（可调 50-1000）确定性模式数据（4KB 块 + 块序号），读回校验块序号与 MD5，报告写/读速度与「疑似扩容」结论，测试文件用后即删。走 `lib\approve.js` 确认门（写盘类）。
- **调度框架**：与 03 同构副本，`peri_` 前缀。候选全部 `green`（外设监听/查询类）。
- 配置与超时：`pollTimeoutMs: 10000`；`peri_tool_run` 工具级 `timeoutMs: 1800000`（上限，单工具实际超时取条目 `timeoutMs`，当前候选 60000/600000）。
- ✅ 接线冒烟通过（内置扩容检测注册成功、无审批服务 fail-closed、空库→空目录、候选不可调度；测试脚本 `temp\smoke-test-wiring.mjs`，2026-08-23）。

### 7.2 工具收录（剩余任务）

候选 4 款（`knowledge\candidates.peripheral.json`）：

| 工具 | 仓库 | 定位 | 收录注意 |
|------|------|------|----------|
| kbt | bloznelis/kbt（MIT，391★） | 键盘测试（TUI） | 首选 |
| MouseTester | microe1/MouseTester（MIT，344★） | 鼠标回报率/轨迹 | GUI |
| CompuTester | GitHub（MIT，2★） | 网页版检测（离线 HTML） | 需 start 包装打开；与 03 重叠，需论证增量价值 |
| ChipInfo | GitHub（MIT，4★） | U盘主控识别 | Python 依赖；停更；仅 Phison/SMI/Alcor |

收录流程与其他调度插件相同。**只收宽松协议；GPL/MPL 一律不收录。**

### 7.3 诚实缺口

- **ChipGenius（主控识别最全）**：闭源，无完全对等的宽松协议替代品（ChipInfo 仅覆盖部分主控且停更）。文档化缺口。
- **U盘量产工具**：几乎全部闭源厂商工具，不收录；主控识别后引导用户自寻厂商工具。
