# ⑨ 磁盘基准插件（only-u-disk-benchmark）

## 1. 概述

功能域：**磁盘性能测试**。调度宽松协议的磁盘基准工具（顺序/随机读写测速、IOPS）。对标图吧工具箱「硬盘工具」分类下的 CrystalDiskMark / AS SSD Benchmark / HD Tune 基准能力。**写盘类基准执行前必须经用户确认。**

- 包名：`only-u-disk-benchmark`
- 开发状态：**已实现**（调度框架代码完成，见 `插件文档\插件\only-u-disk-benchmark\`；工具收录待实测，实测前知识库为空 = 不可调度）
- 插件形态：标准 dsh.bundle 包，注册工具 `dbench_tool_list` / `dbench_tool_run`
- 与 04 分工：04 管磁盘**健康与修复**（SMART/坏道），本插件管磁盘**性能基准**（测速）——不重复

## 2. 构成

```
plugins\only-u-disk-benchmark\
  package.json  cordis.patch.yml  index.js
  lib\
    catalog.js   runner.js   exitcodes.js   # 调度框架（与其他调度插件各带副本，包自足）
  knowledge\
    disk-benchmark-tools.json       # 生效知识库（空 = fail-closed）
    candidates.disk-benchmark.json  # 候选：CrystalDiskMark / DiskSpd（待实测）
    README.md
  tools\                            # 工具二进制随包分发（当前为空）
```

## 3. 应用场景

| 场景 | 触发条件 | 本插件做什么 |
|------|----------|--------------|
| A 硬盘测速 | 想知道盘快不快、是否为瓶颈 | 调度测速工具，输出顺序/随机读写结果 |
| B 换盘对比 | 新盘到手验货 | 基准跑分对比（GUI 工具给用户自己点） |

## 4. 场景提示词（直接复制进 TUI 使用）

**场景 A「硬盘测速」**
> 帮我测一下这块盘的读写速度。用只读或写临时测试文件的方式都行，写盘类测试执行前先向我确认。

**场景 B「换盘对比」**
> 新盘到了，帮我列出可用的磁盘测速工具，GUI 工具我来自己操作，命令行工具你帮我跑并解释结果。

## 5. 使用方法

1. 用户描述需求 → `dbench_tool_list` 列工具（含风险与 tier）→ `dbench_tool_run({ tool, params })`。
2. 写盘类基准（DiskSpd）弹确认条 → 用户允许才执行 → 结构化结果整理成结论。

## 6. 安装方法

```bat
cd dsh
pnpm dsh plugin --profile dsh-tui add ..\plugins\only-u-disk-benchmark
```

纯 harness：`dsh plugin --profile ops add ..\plugins\only-u-disk-benchmark`。

## 7. 开发要点

### 7.1 已实现（调度框架）

- 与 03 同构的框架副本，工具名 `dbench_` 前缀避免跨插件冲突。
- tier 规则：`green`（GUI 工具，用户自行操作）不弹确认；`red`（写盘基准）先 `approval.request` 确认，拒绝返回结构化 `tool-denied`；无审批服务 fail-closed。
- 配置与超时：`cordis.patch.yml` 配置键 `pollTimeoutMs: 10000`；`dbench_tool_run` 工具级 `timeoutMs: 1800000`（上限，单工具实际超时取知识库条目 `timeoutMs`，当前候选 900000/1800000）。条目字段：`argTemplate`、`outPattern`、`exitCodes`、`maxOutBytes: 524288`。
- ✅ 接线冒烟通过（空库→空目录、未知工具抛错、候选 `verified:false` 不可调度；测试脚本 `temp\smoke-test-wiring.mjs`，2026-08-23）。

### 7.2 工具收录（剩余任务）

候选 2 款（`knowledge\candidates.disk-benchmark.json`，未验证前不可调度）：

| 工具 | 仓库 | 定位 | tier | 收录注意 |
|------|------|------|------|----------|
| CrystalDiskMark | hiyohiyo/CrystalDiskMark（MIT） | 顺序/随机读写测速 | green | GUI-only，无 CLI；启动 GUI 供用户自行点测 |
| DiskSpd | microsoft/diskspd（MIT） | 吞吐/IOPS 专业基准 | red | 写盘测试，确认门；CLI 参数已文档化，实测后固定 argTemplate |

收录流程：实测 CLI → 填 `audit.cliEvidence` → 二进制 + LICENSE 进 `tools\<id>\` → 条目改 `verified: true`、`schedulable: true` 移入 `disk-benchmark-tools.json`。**只收宽松协议（MIT/BSD/Apache-2.0/Unlicense/zlib），GPL/MPL 等传染性协议一律不收录。**（CrystalDiskMark 仓库无 LICENSE 文件，收录时需留存官网许可页证据。）
