# ⑫ 网络工具插件（only-u-network）

## 1. 概述

功能域：**网络诊断/测速**。内置两个只读脚本（Wi-Fi 扫描、端口检查）+ 调度宽松协议的第三方网络工具（可视化 ping、路由追踪、测速、带宽压测）。对标图吧工具箱「网络工具」分类（Ping 类、测速类、IP 扫描类）。

- 包名：`only-u-network`
- 开发状态：**已实现**（内置扫描/端口可直接用；调度框架完成，工具收录待实测）
- 插件形态：标准 dsh.bundle 包，注册工具 `net_tool_list` / `net_tool_run` / `net_wifi_scan` / `net_port_check`

## 2. 构成

```
plugins\only-u-network\
  package.json  cordis.patch.yml  index.js
  lib\
    catalog.js   runner.js   exitcodes.js   # 调度框架（各带副本，包自足）
    runScript.js                            # 内置脚本执行器
  assets\
    wifi-scan.ps1      # 附近 Wi-Fi + 已保存配置（netsh，只读）
    port-check.ps1     # host:port 连通性 / 本机监听端口（只读）
  knowledge\
    network-tools.json        # 生效知识库（空 = fail-closed）
    candidates.network.json   # 候选：gping / Trippy / speedtest-go / iperf3（待实测）
    README.md
  tools\                      # 工具二进制随包分发（当前为空）
```

## 3. 应用场景

| 场景 | 触发条件 | 本插件做什么 |
|------|----------|--------------|
| A Wi-Fi 排查 | 连不上网、信号差 | net_wifi_scan 看附近网络与信号强度 |
| B 端口连通性 | 某服务连不上 | net_port_check(host, port) 测试 TCP 连通 |
| C 本机监听排查 | 怀疑有异常程序监听 | net_port_check 无参列监听端口 + 进程 |
| D 网速测试 | 「网速好慢」 | net_tool_run（speedtest-go --json，收录后） |
| E 延迟/丢包可视化 | 游戏卡顿排查 | net_tool_run（gping 多目标延迟曲线，收录后） |

## 4. 场景提示词（直接复制进 TUI 使用）

**场景 A「Wi-Fi 排查」**
> 帮我看看附近有哪些 Wi-Fi、信号怎么样，再看看这台电脑保存过哪些网络。只做只读扫描。

**场景 B「端口检查」**
> 帮我测一下这台机器能不能连上 192.168.1.100 的 3389 端口；顺便看看本机哪些程序在监听端口。

**场景 D「网速测试」**
> 帮我测一下网速，先列出可用的测速工具，说明会消耗多少流量再执行。

## 5. 使用方法

1. Wi-Fi/端口：直接调内置 `net_wifi_scan` / `net_port_check`（只读，不弹确认）。
2. 测速/追踪 → `net_tool_list` → `net_tool_run({ tool, params })`；大流量条目（iperf3）执行前弹确认。

## 6. 安装方法

```bat
cd dsh
pnpm dsh plugin --profile dsh-tui add ..\plugins\only-u-network
```

纯 harness：`dsh plugin --profile ops add ..\plugins\only-u-network`。

## 7. 开发要点

### 7.1 已实现

- **内置脚本 2 个（可用）**：`net_wifi_scan`（`netsh wlan show networks mode=bssid` + 已保存配置；明文密码查看明确不提供——隐私边界）、`net_port_check`（`Test-NetConnection` 或 `Get-NetTCPConnection` 监听清单）。均只读，UTF-8 输出。
- **调度框架**：与 03 同构副本，`net_` 前缀。候选 tier：gping/Trippy/speedtest-go/iperf3 均 `green`（不写盘；iperf3 备注大流量风险）。
- 配置与超时：`pollTimeoutMs: 10000`；`net_tool_run` 工具级 `timeoutMs: 1800000`（上限，单工具实际超时取条目 `timeoutMs`，当前候选 120000-600000）。
- ✅ 接线冒烟通过（内置 2 工具注册成功、空库→空目录、候选不可调度；测试脚本 `temp\smoke-test-wiring.mjs`，2026-08-23）。

### 7.2 工具收录（剩余任务）

候选 4 款（`knowledge\candidates.network.json`）：

| 工具 | 仓库 | 定位 | 收录注意 |
|------|------|------|----------|
| gping | orf/gping（MIT，12.6k★） | 多目标延迟可视化（TUI） | 交互式，非交互参数待实测 |
| Trippy | fujiapple852/trippy（Apache-2.0，7.5k★） | 路由追踪（TUI） | 与 tracert 能力重叠，需论证增量价值 |
| speedtest-go | showwin/speedtest-go（MIT，825★） | 网速测试（--json） | 首选 |
| iperf3 | esnet/iperf（BSD-3-Clause，8.7k★） | 局域网带宽压测 | 需对端 iperf3 服务端；大流量 |

收录流程与其他调度插件相同。**只收宽松协议；GPL/MPL 一律不收录。**

### 7.3 诚实缺口

- **局域网 IP/端口扫描器（Angry IP Scanner 类）**：GPL，无宽松协议替代品收录。`net_port_check` 单点检查 + `Get-NetNeighbor`（ARP）可覆盖常见排查。
- **Wi-Fi 密码查看器（WirelessKeyView 类）**：内置脚本刻意不提供明文密码（隐私/滥用风险边界）。
