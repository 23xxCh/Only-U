# ⑮ 系统维护插件（only-u-sys-maintain）

## 1. 概述

功能域：**系统维护（启动项/运行库/驱动/文件恢复）**。内置两个脚本（驱动清理、DirectX 修复）+ 调度宽松协议的第三方维护工具。对标图吧工具箱「系统工具」分类（Autoruns、DirectX Repair、运行库安装、文件恢复、启动项管理等）。

**写系统类操作（注册表/启动项/驱动/运行库）全部走确认门。**

- 包名：`only-u-sys-maintain`
- 开发状态：**已实现**（内置驱动/DX 可直接用；调度框架完成，工具收录待实测）
- 插件形态：标准 dsh.bundle 包，注册工具 `maint_tool_list` / `maint_tool_run` / `maint_driver_clean` / `maint_dx_repair`
- 与 02/05 分工：02 管白名单文件清理；05 管系统镜像修复；本插件管**启动项/运行库/驱动/文件恢复**——不重复

## 2. 构成

```
plugins\only-u-sys-maintain\

  lib\

  assets\
    driver-clean.ps1   # pnputil 枚举驱动包（只读）/ 卸载 oem*.inf（写系统，确认门）

```

## 3. 应用场景

| 场景 | 触发条件 | 本插件做什么 |
|------|----------|--------------|
| A 启动项排查 | 开机慢、启动项太多 | maint_tool_run（go-autoruns 只读清单 / AutoRunManager 管理，收录后） |
| B 驱动残留清理 | 旧设备驱动残留 | maint_driver_clean 先列清单；卸载走确认门 |
| C DirectX 修复 | 缺 d3dx9_xx.dll 等组件 | maint_dx_repair（确认门，需联网） |
| D 运行库安装 | 软件报缺 VC++ 运行库 | maint_tool_run（vcredist /ai，收录后；确认门） |
| E 文件恢复 | 误删文件找回 | maint_tool_run（FileRecoveryTool，收录后；确认门） |

## 4. 场景提示词（直接复制进 TUI 使用）

**场景 A「启动项」**
> 帮我看看启动项都有什么，先只读列清单，有可疑的我确认后再说怎么处理。

**场景 B「驱动清理」**
> 帮我列出已安装的第三方驱动包，找出明显残留的旧驱动。卸载前先向我确认，说明卸载会影响什么。

**场景 C「DirectX 修复」**
> 游戏报缺 d3dx9_43.dll，帮我修复 DirectX 运行库。先说明会做什么（联网下载微软官方安装包 + 静默安装），我确认后再执行。

## 5. 使用方法

1. 驱动清理：`maint_driver_clean` 无参只列清单（只读）；传 `inf: oem12.inf` 卸载 → **弹确认条**。
2. DirectX：`maint_dx_repair` → **弹确认条** → 微软官方下载 + /Q 静默安装（可能弹 UAC）。
3. 其他 → `maint_tool_list` → `maint_tool_run({ tool, params })`；写系统类条目（tier: red）弹确认条。

## 6. 安装方法

```bat
cd dsh
pnpm dsh plugin --profile dsh-tui add ..\plugins\only-u-sys-maintain
```

纯 harness：`dsh plugin --profile ops add ..\plugins\only-u-sys-maintain`。

## 7. 开发要点

### 7.1 已实现

- **内置脚本 2 个（可用）**：`maint_driver_clean`（`pnputil /enum-drivers` 清单 → `/delete-driver oemX.inf /uninstall /force` 卸载；卸载走确认门）、`maint_dx_repair`（微软官方直链下载 dxwebsetup → `/Q` 静默安装；确认门 + 联网依赖 + UAC 提示；离线时返回引导信息）。均走 `lib\approve.js`（卸载/安装为写系统操作）。
- **调度框架**：与 03 同构副本，`maint_` 前缀。候选 tier：go-autoruns/binwalk `green`（只读），其余 `red`（写系统）。
- 配置与超时：`pollTimeoutMs: 10000`；`maint_tool_run` 工具级 `timeoutMs: 1800000`（上限，单工具实际超时取条目 `timeoutMs`，当前候选 120000-1800000）。
- ✅ 接线冒烟通过（内置 2 工具注册成功、卸载模式无审批服务 fail-closed、空库→空目录、候选不可调度；测试脚本 `temp\smoke-test-wiring.mjs`，2026-08-23）。

### 7.3 诚实缺口

- **DDU（显卡驱动彻底卸载）**：闭源；`maint_driver_clean`（pnputil）为部分替代（无安全模式引导、无全链路清理）。
- **Recuva 级深度恢复**：闭源；FileRecoveryTool 为轻量替代。
- **注册表深度清理（CCleaner 类）**：闭源；Kudu（05）提供带备份的注册表清理，走确认门。
