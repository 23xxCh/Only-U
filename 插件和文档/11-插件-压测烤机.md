# ⑪ 压测烤机插件（only-u-stress-test）

## 1. 概述

功能域：**压测/烤机/基准**。内置 `stress_winsat`（Windows 自带 GPU 图形基准）+ 调度宽松协议的第三方压测工具（CPU 压测、GPU 压测、显存测试、CPU 跑分）。对标图吧工具箱「烤机工具」分类（FurMark、AIDA64 稳定性测试、CPU 跑分类）。

**压测为高负载操作，可能引起过热、降频甚至蓝屏——全部走确认门。**

- 包名：`only-u-stress-test`
- 开发状态：**已实现**（内置 winsat 可直接用；调度框架完成，工具收录待实测）
- 插件形态：标准 dsh.bundle 包，注册工具 `stress_tool_list` / `stress_tool_run` / `stress_winsat`

## 2. 构成

```
plugins\only-u-stress-test\
  package.json  cordis.patch.yml  index.js
  lib\
    catalog.js   runner.js   exitcodes.js   # 调度框架（各带副本，包自足）
    runScript.js  approve.js               # 内置脚本执行器 + 审批门
  assets\
    winsat.ps1                  # winsat graphics GPU 图形基准（内置，高负载）
  knowledge\
    stress-test-tools.json      # 生效知识库（空 = fail-closed）
    candidates.stress-test.json # 候选：stressy / ferritest / MyGPU / memtest_vulkan / cpu-benchmark / CoreMark
    README.md
  tools\                        # 工具二进制随包分发（当前为空）
```

## 3. 应用场景

| 场景 | 触发条件 | 本插件做什么 |
|------|----------|--------------|
| A CPU 稳定性验证 | 超频/清灰后确认稳定性 | stressy 类 CPU 压测（收录后；确认门） |
| B GPU 烤机 | 怀疑显卡过热/花屏 | stress_winsat（内置）或 ferritest/MyGPU（收录后；确认门） |
| C 显存检测 | 花屏怀疑显存故障 | memtest_vulkan（收录后；确认门） |
| D 跑分对比 | 验机/装机看性能 | cpu-benchmark / CoreMark（收录后；确认门） |

## 4. 场景提示词（直接复制进 TUI 使用）

**场景 A「CPU 稳定性」**
> 帮我做一次 CPU 稳定性压测。先说明压测时长和影响（可能过热），我确认后再开始；测试中提醒我关注温度。

**场景 B「GPU 烤机」**
> 帮我跑一次 GPU 图形基准看看显卡稳不稳定，执行前先向我确认。

## 5. 使用方法

1. 用户提出压测/跑分需求 → 模型先说明风险（高负载/过热/蓝屏可能）。
2. `stress_winsat` 或 `stress_tool_run({ tool, params })` → **一律弹确认条**（内置与调度都走 approval）→ 用户允许才执行。
3. 建议配合 10 的 `mon_nvidia_smi` / `ops_diagnose` 观察温度基线。

## 6. 安装方法

```bat
cd dsh
pnpm dsh plugin --profile dsh-tui add ..\plugins\only-u-stress-test
```

纯 harness：`dsh plugin --profile ops add ..\plugins\only-u-stress-test`。

## 7. 开发要点

### 7.1 已实现

- **内置 `stress_winsat`（可用）**：跑 `winsat graphics -dx11`（Windows 自带 GPU 图形基准，约 1-3 分钟）。走 `lib\approve.js` 审批门——无审批服务 fail-closed，拒绝返回结构化 `tool-denied`。
- **调度框架**：与 03 同构副本，`stress_` 前缀。本域候选全部 `tier: red`（高负载）。
- 配置与超时：`pollTimeoutMs: 10000`；`stress_tool_run` 工具级 `timeoutMs: 1800000`（上限，单工具实际超时取条目 `timeoutMs`，当前候选均为 1800000）。
- ✅ 接线冒烟通过（内置 winsat 注册成功、无审批服务 fail-closed、空库→空目录、候选不可调度；测试脚本 `temp\smoke-test-wiring.mjs`，2026-08-23）。

### 7.2 工具收录（剩余任务）

候选 6 款（`knowledge\candidates.stress-test.json`）：

| 工具 | 仓库 | 定位 | 收录注意 |
|------|------|------|----------|
| stressy | GitHub（MIT，活跃） | CPU 压测（-w/-t） | 首选 |
| ferritest | GitHub（MIT，2026-01 新建，0★） | GPU 压测 | 无社区验证，实测前不入生效库 |
| MyGPU | GitHub（MIT，9★） | CUDA GPU 基准 | NVIDIA 限定 |
| memtest_vulkan | GpuZelenograd/memtest_vulkan（zlib，827★） | 显存测试 | 仅测 VRAM；需 Vulkan 驱动 |
| cpu-benchmark | GitHub（MIT，6★） | CPU 跑分 | 依赖 Python 运行时，烤盘代价大 |
| CoreMark | eembc/coremark（Apache-2.0） | CPU 基准（行业标准） | 需自编译 Windows exe，收录成本高 |

收录流程与其他调度插件相同。**只收宽松协议；GPL/MPL 一律不收录。**

### 7.3 诚实缺口

- **FurMark 级 GPU 渲染压力测试、3DMark 级专业跑分**：无宽松协议替代品（原工具闭源/GPL）。内置 winsat + 候选工具为现阶段能力边界。
